# SPYUSDT.P Basis Lab

Một trang nghiên cứu độc lập trong repo D-github-thanh.

## Chức năng
- Live Last Price, Mark Price, Index Price và Funding Rate.
- Tính Raw Basis = Last Price - Index Price.
- Tính Basis %.
- Vẽ Basis và SMA Basis.
- Không cần API key; dùng Binance USDⓈ-M WebSocket.

Binance Mark Price stream cung cấp trực tiếp mark price, index price và funding rate. GitHub Pages có thể phục vụ các file tĩnh trong repository.

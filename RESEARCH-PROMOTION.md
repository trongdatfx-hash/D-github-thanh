# Research publication rule

User instruction, 2026-10-21: do not add new experimental techniques to the web UI until they show improvement. Keep unproven research in scripts, Actions logs and downloadable Actions artifacts; no UI panel or chart/model change for an unproven experiment. The MACD panel has been removed from both entrypoints and MACD report generation removed from the production snapshot workflow. Existing chart indicators are not removed.

For RTH +8 path experiments, compare identical query timestamps with the current SPY V/Composite reference and flat-price control; preserve chronological validation/test boundaries, causal channel snapshots and sparse-case fallbacks, and report coverage. Require positive paired out-of-sample path-error evidence, including active-case checks for guarded methods. The archive has already been inspected, so label results exploratory and require future validation before claiming a trading advantage. Better headline accuracy or a tiny error change is not sufficient evidence by itself. No automatic promotion to the web from research workflows.

# SPYUSDT.P Taker Buy/Sell — Blog Web

Web dashboard cho Binance USDⓈ-M Futures SPYUSDT, hiển thị giá và Taker Buy/Sell realtime.

## URL web
https://cdn.jsdelivr.net/gh/trongdatfx-hash/D-github-thanh@main/

## Nhúng Blogger
Dùng nội dung trong `embed-blogger.html`.

## Tính năng
- SPYUSDT.P
- Binance USDⓈ-M Futures
- 1m/5m/15m/30m/1h/2h/4h/1D
- 1D/3D/7D/14D/30D
- Taker Buy = Binance kline field V
- Taker Sell = total volume - Taker Buy
- NetFlow = Buy - Sell
- REST history + realtime WebSocket
- Zoom / pan / Fit / hover

Lưu ý: đây là web độc lập, chưa truyền dữ liệu vào Pine Script/TradingView.

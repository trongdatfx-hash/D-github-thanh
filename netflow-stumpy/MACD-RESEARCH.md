# MACD versus SPY V / Composite — experimental RTH +8 study

Question: at identical SPY M15 decision times, does standard MACD add more useful information for the next eight RTH candle closes than original-volume SPY V and Composite Strength?

Fixed MACD(12,26,9): EMA12(close)-EMA26(close), signal EMA9(MACD), histogram MACD-signal. EMA uses alpha2/(n+1), SMA seed; the first valid signal is bar34. EMA advances only on observed candles, does not reset at session boundaries, and may use prior NIGHT context. Samples themselves remain continuous PRE-to-POST windows and targets remain strictly within RTH. Formula reference: https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/macd . This is an EMA12/26 approximation, not Fidelity Wealth-Lab's alternate fixed0.15/0.075 exponents.

Clean ablations have common log price/WLR thickness/slope/R2 weights35/15/15/5 percent. Indicator budget is fixed30 percent. PAIR uses tanh(SPY V), tanh(Composite), 15 percent each. MACD uses tanh(MACD/ATR14), tanh(histogram/ATR14), 15 percent each; signal is reconstructable from line-histogram and is not counted as a third redundant channel. COMBINED uses all four indicator channels at7.5 percent each. All signed channels are scaled0.5 before raw Euclidean MASS; only log price gets per-window z normalization. ATR is causal simple14 mean true range. This symmetric tanh representation is a design choice, not proof of a generally optimal indicator scale. Original user indicators and original ten-channel STUMPY remain unchanged in the chart; ORIGINAL8/16 are separate references with their candle-cluster channels and original weights. PRICE ablation uses common weights normalized to100 percent. FLAT and PRIOR are controls.

The MACD-only branch never uses Price×SPY V candle colors, transitions/counter flags or either Strength channel. Tests mutate those fields and verify that MACD distance is unchanged. Python computes eight shared STUMPY MASS channel profiles once per query/window, then combines squared distances with fixed weights. JavaScript independent reference distances are compared with actual STUMPY for all four ablations.

Use the existing +8 study's fixed50/20/30 chronological target-day boundaries. Indicators are precomputed causally; drop all candidates whose sixteen-bar windows have any unavailable feature for either system. Use the same surviving candidates for every model/window, same NY minute, target completed before query sixteen-bar input begins. Maximum20 non-overlapping analogs, at most one per target day. The prior uses all eligible candidate days. Every variant retains the exact same evaluation timestamps. No thresholds, lengths, channel weights or MACD parameters are optimized after evaluating this experiment. Input8 and16 are both reported; best length per representation is chosen only by validation path MAE, never final-test performance.

Primary metric: mean absolute error of all eight predicted closes, expressed as percent of known anchor close. Predictions are pointwise medians of candidate paths scaled by query-time ATR. Endpoint error, three-way direction Brier and directional accuracy are secondary. Direction is positive/negative/unchanged endpoint relative to known anchor; one pseudo-count per class. Brier is a comparative scoring metric, not a claim that frequencies are calibrated. FLAT path uses prior frequencies for its secondary probability reference.

Two fixed primary comparisons: MACD8 versus PAIR8 and MACD16 versus PAIR16. Use97.5 percent paired day-block bootstrap intervals for each (Bonferroni familywise5 percent over those two path hypotheses),5000 draws, blocks of five trading days. Positive path gain means PAIR MAE minus MACD MAE. At least30 final-test days and a positive lower path bound are required for a promising historical result. Brier is secondary. COMBINED comparisons are secondary with unadjusted95 percent intervals. The archive has already been inspected in earlier studies; all findings remain exploratory and require truly future data. This study does not choose a replacement indicator or automatically change the existing chart forecast.

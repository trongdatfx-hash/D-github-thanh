# RTH Structure V2 — primary research goal

Primary target: identify early the distribution of future RTH geometry from PRE–RTH–POST observations. Price is SPYUSDT; indicators include explicit original SPY-volume Strength and Composite SPY+QQQ taker-flow Strength, plus the unchanged WLR/candle-regime features. Existing V1 aeon and its 50/50 ensemble still target three-bar direction and are labeled auxiliary; their probabilities are not reused for the new six-class RTH target.

Input windows: 8/16 consecutive M15 candles, same New York trading date, within PRE 04:00 through POST 20:00. Existing indicator warm-up can include earlier NIGHT observations to preserve the chart formula; only the sample windows exclude NIGHT. Target choices: 60 minutes, 120 minutes, or whole RTH/remaining RTH. PRE predicts the current-day opening segment. During RTH, only unobserved bars after the last closed candle are targets. POST and the RTH-close boundary predict the next trading-day opening. Late RTH with fewer than four remaining bars has no new geometry forecast. A previous valid query can be displayed as an explicitly dated reference, not a current forecast.

RTH labels: UP_TREND / DOWN_TREND require path efficiency >=0.45 and absolute segment displacement >=0.6 query-time ATR14. RANGE requires high-low span <=1.5 ATR and efficiency <0.35. UP_THEN_DOWN / DOWN_THEN_UP require an interior close peak/trough >=0.8 ATR followed by an opposite retracement >=0.75 ATR and at least 60% retracement of the prior excursion. Remaining cases are MIXED. Reversal is tested before trend. Labels are defined after the target segment completes, used as outcomes only, and never supplied to feature matching. Segment paths/returns are anchored to their own RTH starting open, not to an unknown future absolute price projection. Thresholds are fixed exploratory design choices, not validated universal chart patterns.

Analog candidates match the same NY decision minute, PRE/RTH/POST phase and actual target length, including early-close adjustments. A candidate's full target and input must complete before the query input starts. Maximum 20 matches, one per target RTH day, and non-overlapping full input-to-target intervals. Query endpoints are passed explicitly to Python STUMPY; queries need not be the final row of the source. MASS/browser parity is tested on all admitted candidate distances. The ten-channel chart-state metric is shared with the prior models.

Historical evaluation: use the final 40% of complete RTH target dates at the latest query's clock/phase; each evaluation forecast has only mature earlier candidates. Require >=20 candidate days and >=12 selected matches; publish the actual number of scored days, not total bars. Both model and baseline use one pseudo-count per each of six geometry families. Score six-class accuracy and Brier versus all earlier eligible same-context cases, with paired five-day moving-block bootstrap intervals. Frequencies/Wilson intervals remain exploratory and uncalibrated; testing multiple configurations is not corrected by these intervals. This is retrospective OOS, not a forward trade record or transaction-cost backtest.

Calendar: America/New_York handles DST. Existing full-day holiday rules are used for supported 2025–2028 dates, with the 2025-01-09 closure and 2027-12-31 New Year exception. Scheduled early closes are 13:00 RTH / 17:00 extended-session end on 2025-07-03, 2025-11-28, 2025-12-24, 2026-11-27, 2026-12-24, 2027-11-26, 2028-07-03 and 2028-11-24. Source: https://www.nyse.com/trade/hours-calendars and published NYSE annual calendars. Unscheduled halts are not modeled. This calendar layer does not alter the existing chart.

The existing STUMPY GitHub job creates and validates this report every scheduled run. Source timestamps, forecast issue time and target dates are separate. A newly generated report from an old archive is not a live RTH forecast. Source-age and expired-target warnings must remain visible. If collection is blocked (e.g. Binance HTTP 451), preserve the real archived data and never fabricate fresh candles.

## Phase coverage and query checkpoints

Reports include AUTO (latest valid PRE/POST-window query) and four predetermined retrospective checkpoints: PRE 09:00, RTH 10:00, RTH 13:00, POST 20:00 New York. Each supports 8/16 input bars and 60/120 minutes or remaining/full RTH targets. A preset must match its actual phase; RTH 13:00 does not become a POST forecast on a 13:00 close day. Historical/canonical query times are prominently dated; a past target or old source remains a reference. Identical query tasks are deduplicated across AUTO and checkpoints. These are initial research checkpoints, not a claim to have tested every possible decision minute.


## Pivot / divergence experimental grouping (report v3)

The chart is unchanged. SPY high/low pivots reuse confirmedPricePivots from geometry.mjs (left 3, right 2, prominence 0.12 ATR). Known time is the CLOSE of the second right bar, never the pivot bar. Pivot context resets at each NY PRE-to-POST day or data gap and may precede the 8/16-bar matching window; ATR uses the original causal warm-up.

Structure uses the latest confirmed high/low and the most recent same-side predecessor 6–160 bars apart. Moves larger than 0.15 current causal ATR define HH/HL (UP), LH/LL (DOWN), HH/LL (EXPANDING), LH/HL (CONTRACTING); missing/flat sides are UNRESOLVED.

confirmedDivergences is applied separately to original-volume SPY V and Composite Strength, with price swing >=0.15 ATR and absolute Strength change >=0.06. Signals expire after 8 closed M15 bars. Both sources agreeing gives bullish/bearish; opposite sources give mixed; absent/expired signals give none. QQQ price and standalone QQQ Strength are not substituted. No-signal does not prove absence of divergence: it includes insufficient pivots.

Fixed hierarchy: same structure + divergence, then same structure, then active divergence only, then original STUMPY. Each informative level requires >=12 selected non-overlapping analogs; at most 20. Unresolved structures skip structural levels and may use active-divergence-only groups. The no-signal state never activates divergence-only grouping. This level was added after observing sparse PRE coverage in the initial pivot trial, not chosen by predictive gain; all results remain post-hoc. MASS distances/weights and six RTH outcome labels remain unchanged. Groups only filter the already causal candidate pool; no label-dependent ranking.

Both variants use identical evaluation timestamps, outcomes and historical candidate availability. Sparse-group days remain in the evaluation through fallback; report exact/structure/divergence/base coverage. Compare paired Brier (original minus grouped; positive helps grouped) with 1000 paired 5-day moving-block bootstrap samples. This is a post-hoc exploratory addition, not a newly untouched test. No threshold or hierarchy is selected by test performance, no multiple-comparison correction, and future validation is required. Snapshot group tables are descriptive archive counts, not OOS metrics. Existing aeon V1 still has a different 3-bar target.

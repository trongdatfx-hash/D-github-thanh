# RTH +8 price reference (experimental)

The chart toggle is off by default and saved by Lưu setup. It supports SPY M15 only. It never changes OHLC or Strength calculations. A separate canvas uses chart coordinate APIs and does not add forecast bars to candle data, time indices or autoscaling. The dashed line starts at the last CLOSED SPY close. Eight points represent the next eight candle closes at their usual chart open timestamps. The shaded band is historical pointwise P10/P90, not an 80% simultaneous prediction interval. The pointwise median may combine different historical paths and need not be one likely coherent future path.

Inputs: original ten WLR/Price×SPY V/Composite channels, plus confirmed Pivot context only for pivot candidates. Historical candidates use the same NY decision minute, exact eight-bar RTH target, mature outcomes before the sixteen-bar query input begins. At most20 non-overlap analogs, one target day each; prior uses all eligible same-clock days. Future closes are scaled by ATR known at each historical query and anchored to that query close (including any next-open gap). Current projection rescales by current causal ATR and current closed SPY close.

Candidates: FLAT (hold current price), PRIOR (all eligible days), STUMPY8/16, PIVOT8/16. aeon3 is excluded due to a different forecast horizon. First50% of complete target days is initial history, next20% validation selects minimum mean eight-step absolute path error as percent of anchor price, last30% is scored without choosing on its performance. No final-test winner switching. Report all model scores, selection boundaries and per-query errors. Final path gain over flat uses paired target-day means and 1000 five-day moving-block bootstrap draws; >=30 test days and lower bound>0 required for a positive historical signal. Selection among six alternatives and prior research on this archive make this exploratory; a positive interval is not forward validation or trading profitability.

The flat baseline is eligible to win. In that case display an honest flat reference; do not manufacture a curved forecast. Up/down/unchanged frequencies come from historical matched outcomes with one pseudo-count each (prior group for FLAT). They are separate from the median price-change percentage and are not calibrated confidence or trading win rates. No new probability is inferred from classification accuracy or a line's shape.

The browser computes only when enabled, in a dedicated worker. It uses the active chart's causal feature rows and full-precision archived vectors; Python actual STUMPY MASS remains the selection/evaluation backend, and browser distances use the shared parity-verified equivalent. No new Binance request or external price source is introduced. A historical training archive may be older than the live query and its timestamp stays visible. Hide the line on symbol/timeframe mismatch, API staleness, feature/closed-candle timestamp mismatch, missing history, fewer than20 candidate days, fewer than12 selected matches, or inability to fit exactly eight new candles before the actual NYSE RTH close. Refresh only on a new closed candle; live intrabar OHLC never enters the query. The layer does not extrapolate into POST or the next day.

Calendar and target-day rules reuse rth-structure.mjs, including NY DST, supported holiday years and early closes. A historical chart point before the selector's test period cannot reuse that future selection.
